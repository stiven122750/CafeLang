REGLAS DEL PROYECTO — CAFELANG

REGLAS

REGLA 1 — CAFÉ DISPONIBLE

Se verifica si existe café disponible antes de permitir que un cliente realice un pedido.

SI (cafeDisponible == VERDADERO) {
    MOSTRAR("El café está disponible")
}
SINO {
    MOSTRAR("No hay café disponible")
}


REGLA 2 — CLIENTE FRECUENTE

Se identifica si el cliente es frecuente mediante la cantidad de puntos acumulados.

SI (puntosCliente >= 500) {
    clienteFrecuente = VERDADERO
    MOSTRAR("El cliente es frecuente")
}
SINO {
    clienteFrecuente = FALSO
}


REGLA 3 — TEMPERATURA ADECUADA

El agua debe encontrarse dentro de un rango adecuado para preparar el café.

SI (temperaturaAgua >= 85 Y temperaturaAgua <= 95) {
    MOSTRAR("La temperatura del agua es adecuada")
}
SINO {
    MOSTRAR("La temperatura no es adecuada")
}


REGLA 4 — PREPARACIÓN DEL CAFÉ

Para preparar el café debe existir agua disponible y el café debe estar molido.

SI (cafeMolido == VERDADERO Y aguaDisponible == VERDADERO) {
    PREPARAR
    pedidoPreparado = VERDADERO
    MOSTRAR("El café puede prepararse")
}
SINO {
    MOSTRAR("No se puede preparar el café")
}


REGLA 5 — COMPRA AUTORIZADA

La compra puede realizarse si el cliente tiene suficiente saldo o cuenta con un cupón.

SI (saldoCliente >= precioCafe O tieneCupon == VERDADERO) {
    MOSTRAR("Compra autorizada")
}
SINO {
    MOSTRAR("Compra rechazada")
}


REGLA 6 — CAFÉ CON LECHE

El cliente puede solicitar café con leche solamente cuando hay leche disponible.

SI (tieneLeche == VERDADERO) {
    tipoCafe = "Cafe con leche"
    MOSTRAR("Se puede preparar café con leche")
}
SINO {
    MOSTRAR("No hay leche disponible")
}


REGLA 7 — CÁLCULO DEL TOTAL DEL PEDIDO

El total se obtiene multiplicando la cantidad de tazas por el precio del café.

FUNCION calcularTotal(ENTERO cantidad, DECIMAL precio) {
    RETORNAR cantidad * precio
}

DECIMAL total

total = calcularTotal(cantidadTazas, precioCafe)

MOSTRAR(total)

Esta regla permite que una función reciba parámetros y devuelva un valor que puede almacenarse en una variable.


REGLA 8 — APLICACIÓN DE DESCUENTO

Se aplica un descuento cuando el cliente tiene suficientes puntos.

FUNCION calcularDescuento(DECIMAL precio, ENTERO puntos) {

    SI (puntos >= 500) {
        RETORNAR precio * 0.90
    }

    RETORNAR precio
}

DECIMAL precioFinal

precioFinal = calcularDescuento(precioCafe, puntosCliente)

MOSTRAR(precioFinal)


REGLA 9 — CAFÉ DE BUENA CALIDAD

Se determina si el café tiene una calidad suficiente para ser servido.

SI (calidadCafe >= 80) {
    MOSTRAR("El café tiene buena calidad")
}
SINO {
    MOSTRAR("El café no cumple con la calidad requerida")
}


REGLA 10 — PREPARACIÓN COMPLETA

Antes de servir un pedido se comprueba que el café haya sido tostado, molido y preparado.

SI (cafeTostado == VERDADERO Y cafeMolido == VERDADERO) {

    SI (pedidoPreparado == VERDADERO) {
        SERVIR
        MOSTRAR("Pedido listo para el cliente")
    }
    SINO {
        MOSTRAR("El pedido todavía no está preparado")
    }

}
SINO {
    MOSTRAR("El café no está listo para preparar")
}


REGLA 11 — CONTROL DE VARIAS TAZAS

Se utiliza un ciclo para servir varias tazas del mismo pedido.

ENTERO tazasServidas = 0

MIENTRAS (tazasServidas < cantidadTazas) {

    SERVIR

    tazasServidas = tazasServidas + 1
}

Esta regla permite demostrar el uso de una estructura repetitiva.


REGLA 12 — PEDIDO LISTO PARA SERVIR

Se comprueba que todas las condiciones necesarias estén cumplidas antes de entregar el pedido.

SI (pedidoPreparado == VERDADERO Y cafeDisponible == VERDADERO) {

    SI (temperaturaAgua >= 85 Y temperaturaAgua <= 95) {
        SERVIR
        MOSTRAR("Pedido listo para servir")
    }
    SINO {
        MOSTRAR("La temperatura no permite servir el café")
    }

}
SINO {
    MOSTRAR("El pedido no está listo")
}


REGLA 13 — COMPRA CON BENEFICIO

Se calcula el precio final dependiendo de los puntos acumulados por el cliente.

FUNCION precioConBeneficio(DECIMAL precio, ENTERO puntos) {

    SI (puntos >= 1000) {
        RETORNAR precio * 0.80
    }

    SI (puntos >= 500) {
        RETORNAR precio * 0.90
    }

    RETORNAR precio
}

DECIMAL precioFinal

precioFinal = precioConBeneficio(precioCafe, puntosCliente)

MOSTRAR("Precio final:")
MOSTRAR(precioFinal)

Esta regla utiliza dos condiciones diferentes dentro de una misma función.


REGLA 14 — VERIFICACIÓN DEL PEDIDO

Antes de procesar un pedido se solicita la cantidad de tazas y se verifica que sea válida.

ENTERO cantidad

LEER(cantidad)

SI (cantidad > 0 Y cantidad <= 10) {
    pedidoActivo = VERDADERO
    MOSTRAR("Cantidad de tazas aceptada")
}
SINO {
    pedidoActivo = FALSO
    MOSTRAR("Cantidad de tazas no válida")
}

Esta regla incorpora entrada de datos mediante LEER.


REGLA 15 — PROCESO COMPLETO DE UN PEDIDO

Se combinan varias características del lenguaje para representar el proceso básico de una compra.

ENTERO cantidadTazas
DECIMAL total
DECIMAL precioFinal

LEER(cantidadTazas)

SI (cafeDisponible == VERDADERO Y cantidadTazas > 0) {

    total = calcularTotal(cantidadTazas, precioCafe)

    SI (saldoCliente >= total) {

        SI (cafeMolido == VERDADERO Y aguaDisponible == VERDADERO) {

            PREPARAR
            pedidoPreparado = VERDADERO

            precioFinal = calcularDescuento(total, puntosCliente)

            SERVIR

            MOSTRAR("Pedido realizado correctamente")
            MOSTRAR(precioFinal)
        }
        SINO {
            MOSTRAR("No se puede preparar el pedido")
        }

    }
    SINO {
        MOSTRAR("Saldo insuficiente")
    }

}
SINO {
    MOSTRAR("No es posible realizar el pedido")
}

Esta regla integra entrada de datos, variables, funciones, condiciones, operadores lógicos, operaciones matemáticas y acciones propias de CafeLang.
